# 🎮 Tic Tac Toe Game

A simple and fun **Tic Tac Toe** game built using **HTML**, **CSS**, and **JavaScript**. This is a **two-player-only** version — AI gameplay is not available yet.

[👉 Click here to play the game!](https://tejagadepalli.github.io/TICTACTOE/)

---

## 📌 Features

* ✅ Classic 3x3 Tic Tac Toe grid
* ✅ Two-player local gameplay (Player X vs Player O)
* ✅ Win detection and draw handling
* ✅ Game reset functionality
* ✅ Clean, modern UI with responsive design

> ℹ️ **Note:** This version supports only two players on the same device.

## 🎯 How to Play

1. The game is played on a 3x3 grid.
2. Player X goes first.
3. Players take turns clicking on empty squares to mark them.
4. The first player to align 3 marks in a row (horizontally, vertically, or diagonally) wins.
5. If all squares are filled and no winner is found, the game ends in a draw.
